# 图标资源

此目录存放小程序的 TabBar 和其他图标资源。

## 需要准备的图标

以下是需要的图标文件（建议尺寸 81px × 81px，PNG 格式）：

### TabBar 图标
- `home.png` - 首页（未选中）
- `home-active.png` - 首页（选中）
- `chart.png` - 统计（未选中）
- `chart-active.png` - 统计（选中）
- `star.png` - 收藏（未选中）
- `star-active.png` - 收藏（选中）
- `admin.png` - 管理（未选中）
- `admin-active.png` - 管理（选中）

## 临时方案

在准备正式图标前，可以：
1. 使用 Emoji 代替图标
2. 使用在线图标生成工具创建简单图标
3. 使用 iconfont.cn 等平台下载图标

## 图标设计建议
- 简洁清晰，符合微信设计规范
- 未选中状态使用灰色调
- 选中状态使用主色调（#10B981 绿色）
- 线条粗细适中，避免过于复杂
