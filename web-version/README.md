# 科研奖励获奖信息查询系统 - Web 版本

## 🚀 快速开始

### 方式一：直接打开（推荐）
1. 双击打开 `index.html` 文件
2. 系统会自动在浏览器中运行
3. 无需安装任何依赖

### 方式二：使用本地服务器
```bash
# 进入项目目录
cd web-version

# 使用 Python 启动简单服务器
python -m http.server 8080

# 或使用 Node.js
npx serve .

# 然后访问 http://localhost:8080
```

## 📁 文件结构

```
web-version/

```

## ✨ 功能特性

### 1. 首页
- 🔍 搜索框：支持姓名、单位、成果名称、奖项名称模糊搜索
- 📊 统计卡片：总获奖数、获奖单位、奖项种类

- 📅 快捷筛选：国家级/省级/市级/年份筛选

### 2. 搜索页面
- 多维度模糊搜索

### 3. 详情页面
- 完整获奖信息展示

## 📱 转换为微信小程序

当前 Web 版本可以轻松转换为微信小程序：

### 需要修改的部分：

1. **存储方式**
   - Web: `localStorage` → 小程序: `wx.setStorageSync`
   
2. **页面路由**
   - Web: 单页应用 → 小程序: 多页面配置
   
3. **网络请求**
   - 当前: 内存数据 → 小程序: `wx.request` 调用后端 API

4. **组件替换**
   - HTML 标签 → 小程序组件 (`view`, `text`, `image` 等)
   - CSS → WXSS

### 转换步骤：

1. 使用微信小程序开发者工具创建新项目
2. 将 `index.html` 中的 HTML 结构转换为 WXML
3. 将 CSS 转换为 WXSS
4. 将 JavaScript 逻辑转换为小程序 Page 对象
5. 配置 `app.json` 页面路由

## 📝 注意事项

1. 当前版本使用模拟数据，实际使用时需要连接后端 API
2. 收藏功能仅在登录后可用
3. 管理功能仅管理员可用
4. 建议使用 Chrome、Firefox、Edge 等现代浏览器
